# 25강 시뮬레이터

로스트아크 무기 25강 시뮬레이터. +24 → +25를 몇 트만에 성공하는지 겨루는 실시간 랭킹 게임.

## 현재 상태

- `index.html`: 동작하는 프로토타입 (Claude Artifact로 배포 예정, `db` capability로 실시간 공유 랭킹 구현됨)
- **디자인 미완성**: 지금 들어간 "대장간" 컨셉 디자인은 요청과 다름 — 실제 로스트아크 강화창 UI를 그대로 재현해야 함. 스크린샷 받는 대로 교체 필요.

## 확률 로직 (확정, 변경 금지)

- 기본 성공 확률: **0.5%** (24강 → 25강)
- 실패 시 보정: 실패할 때마다 시도 확률의 **46.5%**만큼 "장인의 기운" 게이지 누적
- 천장: 장인의 기운 **100%** 도달 시 다음 시도 확정 성공 (장기백)
- 이론상 최대 시도 횟수: 432트

## 진행 방식 (확정)

- 각자 휴대폰으로 동시 참여
- 가상 강화 시뮬레이터 + 실시간 공유 랭킹 (닉네임별 최소 시도 횟수 기준)
